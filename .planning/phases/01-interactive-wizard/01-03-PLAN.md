<objective>
Wire the wizard into the `init` command. Rewrite `runInit` in `lib/cli.js` so bare
`init` (in a TTY, missing required fields) runs `runWizard`, then shows a
masked confirmation summary (WIZ-04) before proceeding to the existing
print/write path. Fully-flagged invocations skip the wizard entirely (WIZ-05,
CI-safe). No-TTY with insufficient flags prints `buildNoTtyError` to stderr and
returns exit code 1 without hanging (WIZ-06). Update `bin/ocp-mcp.js` to await a
possibly-async `runCli`. Existing `--print`/`--write` behavior and the PAT
golden-SHA contract must remain byte-identical.

Purpose: This is the user-visible deliverable — bare `init` no longer errors
(WIZ-01). Phase 2 plugs install execution in after the confirmation step.
Output: rewired `lib/cli.js`, async-safe `bin/ocp-mcp.js`, extended `test/cli.test.js`.
</objective>
