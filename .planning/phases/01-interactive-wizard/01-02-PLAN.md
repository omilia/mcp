<objective>
Build the interactive I/O layer. Create `lib/prompts.js` (thin wrappers over
`node:readline/promises` for choice, free-text, and non-echoing secret input) and
add an async `runWizard` orchestrator to `lib/wizard.js` that drives the prompt
flow: select client (Claude Code / Claude Desktop, WIZ-02) → select auth method
and collect matching credentials (WIZ-03) → return a completed options object.
runWizard prompts ONLY for fields returned by missingPromptFields (WIZ-05 reuse).

Purpose: This is the live prompt experience that makes bare `init` interactive
(WIZ-01). Secret input must never echo (security constraint). No new npm deps —
node:readline/promises only.
Output: `lib/prompts.js` + `runWizard` export in `lib/wizard.js`.
</objective>

  <behavior>
    - askChoice(label, choices, io) prints the label and an enumerated list of choices, reads a line, accepts either the 1-based index or the choice value, re-prompts on invalid input, and resolves to the selected choice value. choices is an array of { value, label }.
    - askText(label, { defaultValue }, io) reads a line; empty input returns defaultValue when provided, otherwise re-prompts; trims surrounding whitespace.
    - askSecret(label, io) reads a line WITHOUT echoing typed characters to the output stream, and resolves to the entered string. The typed characters and the resolved value must never be written to io.output.
    - All three accept an injected io = { input, output } defaulting to { input: process.stdin, output: process.stdout } so tests pass scripted streams; all return Promises.
