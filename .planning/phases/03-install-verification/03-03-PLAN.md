<objective>
Wire prerequisite checks (03-01) and the smoke test (03-02) into `init` and emit a clear PASS/FAIL summary (VER-03). Create `lib/verify.js` that orchestrates: run `checkPrerequisites`; if anything is missing, render exactly what is missing + its install hint and SKIP the smoke test (you cannot smoke-test without uv/node); if prereqs pass, run `smokeTest`; render a PASS/FAIL block (prereqs per-check ✓/✗, smoke ✓/✗) and an overall PASS/FAIL line. Then wire `runVerification` into `finishInit` so it runs AFTER the config write / `claude mcp add` for non-print, non-opt-out runs. Add a `--no-verify-install` escape and skip verification entirely when `--print`. Preserve backward compatibility: `--print` output and the PAT golden-SHA / `--write` tests must stay byte-identical.

Purpose: Success Criterion 3 — "init exits with a clear PASS or FAIL summary; no credentials appear in any output line." Closes VER-01/02/03 by connecting the check layers to the user-facing flow.

Output: `lib/verify.js` + `test/verify.test.js` + edits to `lib/cli.js`.
</objective>
