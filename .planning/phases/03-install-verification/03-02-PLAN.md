<objective>
Create `lib/smoketest.js` — after config is written, start the installed server and confirm tools are reachable (VER-02). The OCP server is a STATELESS tool catalogue, so `tools/list` works WITHOUT OCP credentials (auth is only needed to CALL a tool). The smoke test spawns the resolved run command from `buildRunCommand` (lib/runtime.js) over stdio, performs a minimal MCP handshake (JSON-RPC `initialize` then `tools/list`), reads framed responses under a bounded timeout, and asserts the tools array is non-empty (bonus: contains `read_guide`). It tears the child down cleanly on done/timeout. The spawn/transport is injectable so unit tests simulate the handshake without launching uv; one real integration-style test is guarded/skipped when uv is absent.

This plan also enforces the VER-03 no-leak guarantee at the smoke-test layer: the child receives env (incl. token) but its stdout/stderr is summarized, never dumped verbatim into the returned result.

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-03-05 | Information disclosure | child stdout/stderr dumped verbatim | mitigate | Module never writes child output to process stdout/stderr; reason strings are static templates with no interpolation of child output or env. |
