<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| preflight → child process (node/uv --version) | spawned binary stdout is untrusted text parsed for a version number |
| preflight result → caller stdout | result objects are rendered to the terminal by plan 03-03 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information disclosure | checkNode/checkUv parsing child stdout | mitigate | Parse only the version token from stdout; never copy raw stdout into hints or returned fields. Test asserts a planted secret in stdout never surfaces. |
| T-03-02 | Denial of service | spawn never returns (hung binary) | accept | `--version` is a fast, non-interactive invocation; spawnSync returns promptly. Smoke-test (03-02) owns the long-running timeout concern. |
| T-03-03 | Tampering | ENOENT / malformed version output | mitigate | All spawn calls wrapped in try/catch; unparseable output treated as ok:false found:null, never throws. |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan (node:child_process only). |
</threat_model>
