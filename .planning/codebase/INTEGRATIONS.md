# External Integrations

**Analysis Date:** 2026-06-09

## APIs & External Services

**Omilia Cloud Platform (OCP) — REST API:**
All calls go through `src/ocp/base.py` (`BaseClient`) which prepends `OCP_BASE_URL` and attaches auth headers.

- **Orchestrator API** — Manage apps, agents, canvases, TTS configuration
  - Client: `src/ocp/orchestrator.py` (`OrchestratorClient`)
  - Base path: `orchestrator/api/`
  - Auth: `OCP_BASE_URL` + PAT or Keycloak token

- **MiniApps API** — Search, create, update miniapp components
  - Client: `src/ocp/miniapps.py` (`MiniAppsClient`)
  - Base path: `miniapps/api/`

- **Pathfinder API** — FAQ/knowledge base vector store management
  - Client: `src/ocp/pathfinder.py` (`PathfinderClient`)
  - Base path: `pathfinder/api/v1/`
  - Auth note: requires Bearer JWT; PAT-only returns 401

- **Insights API** — Dialog log search and retrieval
  - Client: `src/ocp/insights.py` (`InsightsClient`)
  - Base path: `dialogs-api/insights/v2/`
  - URL remapping: `https://us1-m.ocp.ai` → `https://us1-a.ocp.ai`, `https://eu1-m.ocp.ai` → `https://eu1-a.ocp.ai` (analytics subdomain differs from management subdomain)

- **Integrations API** — Phone number search
  - Client: `src/ocp/integrations.py` (`IntegrationsClient`)
  - Base path: `integrations/api/`

- **Environments Manager API** — Variable collections
  - Client: `src/ocp/environments_manager.py` (`EnvironmentsManagerClient`)
  - Base path: `envs-manager/api/v1/`

**Omilia Cloud Platform (OCP) — WebSocket:**
- **Chat/Dialog WebSocket** — Real-time multi-turn conversation with deployed Orchestrator apps
  - Client: `src/ocp/chat.py` (`ChatClient`)
  - Protocol: JSON-envelope messages over WebSocket
  - Credentials fetched first via REST (`orchestrator/api/apps/{app_id}/web_chat/`), then WebSocket opened to `chat_url`
  - SDK: `websockets` 16.0

## Data Storage

**Databases:**
- None. The server is stateless — no local database.

**File Storage:**
- Local filesystem only: guide markdown files read at startup from `src/guides/` via `pathlib.Path`

**Caching:**
- In-memory only: Keycloak token cache in `src/ocp/authentication.py` (`Authentication` instance per `BaseClient`). Tokens never persisted to disk.

## Authentication & Identity

**Auth Provider: Keycloak (OCP-hosted)**
- Implementation: `src/ocp/authentication.py` (`Authentication` class)
- Flow: OIDC password grant → `{OCP_BASE_URL}/auth/realms/{realm}/protocol/openid-connect/token`
- Token refresh: automatic with 30-second proactive skew (`TOKEN_REFRESH_SKEW_SECONDS`)
- Revocation endpoint: `{OCP_BASE_URL}/auth/realms/{realm}/protocol/openid-connect/logout`
- Realm: `OCP_KEYCLOAK_REALM` env var (default: `master`)

**Auth Provider: Personal Access Token (PAT)**
- Implementation: inline in `src/ocp/base.py`
- Header sent: `X-OCP-PERSONAL-ACCESS-TOKEN: <token>`
- Source: `OCP_ACCESS_TOKEN` env var

**Auth Priority Order** (first match wins, in `src/ocp/base.py`):
1. `auth_header` constructor argument → `Authorization: Bearer <token>`
2. `OCP_ACCESS_TOKEN` env var → PAT header
3. `OCP_USERNAME` + `OCP_PASSWORD` env vars → Keycloak password grant

## Environment Configuration

**Required env vars:**
- `OCP_BASE_URL` — OCP instance URL (e.g. `https://pub.demo.ocp.ai`). Required for all API calls.

**For PAT auth (default):**
- `OCP_ACCESS_TOKEN` — Personal Access Token

**For Keycloak auth:**
- `OCP_USERNAME`
- `OCP_PASSWORD`
- `OCP_KEYCLOAK_REALM` (optional; default `master`)

**Secrets location:**
- Environment variables only (injected via MCP client config)
- Config generated by `lib/config.js` and written to MCP client config files (e.g. `~/.cursor/mcp.json`, `~/Library/Application Support/Claude/claude_desktop_config.json`)
- No `.env` file committed

## Webhooks & Callbacks

**Incoming:**
- None. The server exposes MCP tools only; no HTTP webhook endpoints.

**Outgoing:**
- None. The server calls OCP APIs on-demand but does not register outgoing webhooks.
